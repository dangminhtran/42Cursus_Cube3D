# Cube3D – 42 School Project

A 3D maze exploration game developed as part of the 42 curriculum. This project simulates a 3D environment using raycasting, inspired by the classic Wolfenstein 3D game, and is built using the MiniLibX graphics library.

---

## 🎮 About

Cube3D is a first-person perspective game where the player navigates through a 3D maze. The game employs raycasting to render the 3D environment from a 2D map, allowing for dynamic exploration.

---

## 🗂 Project Structure

```text
.
├── cub3d/ # Main source files and game logic
├── includes/ # Header files (.h)
├── libft/ # Custom library for utility functions
├── Makefile # Build script
└── README.md # Project documentation

```
## ⚙️ Requirements

- A **POSIX-compliant environment** (Linux/macOS/WSL).
- **MiniLibX** graphics library.
- **Make** and a C compiler (e.g., `gcc`).

---

## 🚀 Installation & Usage

   ```bash

# Clone the repository
   git clone https://github.com/dangminhtran/42Cursus_Cube3D.git
   cd 42Cursus_Cube3D

# Build the project:
  make


# Run the game:
 ./cub3D maps/map_minh.cub

```
